# Next App 機能整合の確認範囲

この資料は、iPhone と Android の実装で利用者に見える機能と状態をそろえるための確認基準です。機能追加時は、ここにある両 OS の観点を満たすことを PR の確認対象にします。

## 便利機能

| 機能 | 両 OS の確認観点 |
| --- | --- |
| 予定 | 端末内保存、一覧、今日の予定、登録、編集、削除、リマインダー |
| 日記 | 作成、写真添付、一覧、編集、削除、端末内保存 |
| 金種計算 | 金額入力、金種内訳、結果表示、端末内保存 |
| 予算・決算（個人用） | Guestの端末内保存、会員登録後の本人専用Firebase移行、帳簿・明細の登録編集削除、収支自動集計、領収書添付、CSV共有、本人以外のアクセス拒否 |
| 会議録音 | 録音、再生、議事録、端末内保存 |
| SNS・お気に入り | 共有先、保存、復元、空状態 |

## 共通の状態

各機能では、少なくとも次の状態を同じ文言と意味で扱います。

- 読み込み中
- データなし
- 通信または保存エラーと再試行
- 権限不足
- 処理中と多重操作防止
- 重要操作の確認と成功・失敗メッセージ

## CI の確認

各 PR では次の必須 CI が成功していることを確認します。

- Android `build-test-lint`
- iPhone `build-test`
- Firebase Emulator `smoke`
